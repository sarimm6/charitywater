# Water Way

An interactive charity: water inspired browser game built with plain HTML, CSS, and JavaScript. Guide water through each course, pour upstream of the line, and fill the jerrycan without losing too much along the way.

## Features

- Animated water physics game rendered on a canvas
- Easy, medium, hard, and random courses
- Sound effects, score tracking, milestones, and win screen
- Responsive layout for desktop and mobile

## Demo
Visit at https://sarimm6.github.io/charitywater/

## How to Run

1. Open `index.html` in a browser, or
2. Serve the folder with a local static server and open the page there.

If you want a quick local server, one simple option is:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000` in your browser.

## Controls

- Press and hold on the canvas to pour water
- Release to stop pouring
- Use the difficulty buttons to switch courses
- Use the reset button to restart the current level

## Project Files

- `index.html` - page structure and game UI
- `style.css` - layout, colors, and responsive styling
- `script.js` - game logic, physics, scoring, and rendering
